# 论文库智能问答系统 (RAG)

这是一个基于 **RAG (检索增强生成)** 架构的论文知识库问答系统。它允许你通过自然语言提问，从本地的论文集合中智能检索并生成答案，答案会注明参考来源。项目同时提供了基础RAG链和基于Agent的两种问答实现。

### 业务现状

- 研究人员需阅读大量本地 PDF 论文，关键信息定位依赖人工翻阅，效率低
- 论文知识分散在个人文件夹中，缺乏统一检索入口，重复查阅成本高
- 通用大模型无法访问私域论文，直接提问存在编造风险

### 当前痛点

- **找得慢**：人工逐篇检索，定位一个结论平均耗时数分钟至数十分钟
- **答不准**：通用模型对私域内容无感知，回答缺乏依据、无法溯源
- **管不住**：论文持续新增，知识库无法自动更新，检索结果逐渐失效

### 项目目标

- 构建私域论文知识库，实现自然语言问答与来源标注
- 支持多文档精准检索，答案可追溯至原文片段
- 实现容器化打包与 CI/CD 自动化部署，形成标准化交付流程

### 项目价值

- **效率提升**：从人工翻阅到秒级问答，关键信息定位时间大幅缩短
- **可信增强**：答案附带参考来源，降低大模型幻觉带来的决策风险
- **可复用交付**：Docker + Jenkins 流水线，形成可复制的 AI 应用交付模板

## 整体架构设计

### 工作流编排

- 文档解析 → 分块 → Embedding → 向量检索 → LLM 生成，链路标准化
- 基础 RAG 链固定“先检索再生成”，流程可控、便于调试
- Agent 模式自主判断是否需要检索，支持多轮对话与工具调用

### 分领域知识库设计

- 按论文主题/来源分块入库，Chroma 向量库统一管理
- 支持增量更新，新增论文可单独索引，不影响已有库
- 元数据保留论文标题、页码，支撑答案溯源

### 混合检索优化

- 向量检索 + 关键词匹配结合，兼顾语义相似与术语精确
- 分块策略平衡上下文完整性与检索粒度，减少信息截断
- 检索结果按相关性排序后注入 Prompt，控制上下文长度

### Rerank 重排序优化

- 初筛召回多篇候选片段，再通过重排序精选 Top-K
- 降低无关片段干扰，提升生成答案的聚焦度与准确率
- 重排序作为可插拔模块，便于后续替换更强模型

## 核心模块设计

### 意图路由设计

- Agent 自主判断：简单问题直接回答，知识型问题触发检索
- 多轮对话中保留上下文，支持追问与指代消解
- 路由逻辑与检索解耦，便于单独优化与测试

### 知识库搭建

- PDF 解析 → 文本清洗 → 分块 → Embedding → 入库，全流程脚本化
- 分块大小与重叠窗口可配置，适配不同论文结构
- 向量库持久化存储，重启不丢失索引

### 检索设计

- 支持多文档同时检索，返回带来源的候选片段
- 检索结果附带相似度分数，便于阈值过滤与质量监控
- 检索失败时可回退至关键词匹配，保证基础可用性

## 其他设计

### 幻觉检测

- 答案强制标注参考来源，无来源内容不输出
- 检索为空时明确告知“未找到依据”，而非编造回答
- 改进效果：降低无依据回答比例，提升答案可信度

### 上下文管理

- 多轮对话保留历史摘要，控制 Token 消耗
- 超长上下文自动截断，优先保留最近轮次与检索片段
- 改进效果：在有限上下文窗口内维持多轮问答连贯性

### 故障闭环机制

- Jenkins 流水线集成 pytest，代码提交自动触发测试
- Docker 镜像构建失败即阻断部署，问题尽早暴露
- Shell 一键部署脚本，降低环境差异导致的交付故障
- 改进效果：形成“提交→测试→构建→部署”闭环，交付可重复、可回滚

## 测试效果

### 技术指标

- 多文档检索命中率：Top-K 召回覆盖目标片段
- 答案溯源率：生成答案附带来源的比例
- 部署成功率：CI/CD 流水线自动构建与部署通过率

### 业务指标

- 单次问答耗时：从提问到返回答案的端到端时间
- 人工检索替代率：可被系统直接回答的问题占比
- 知识库更新效率：新增论文入库所需时间

### 用户体验指标

- 答案可读性：回答结构清晰、直接回应问题
- 来源可信度：参考片段与答案的相关性
- 多轮连贯性：追问场景下上下文保持能力

## 技术栈

- RAG 框架：LangChain
- 向量数据库：Chroma
- 容器化：Docker
- CI/CD：Jenkins + pytest
- 部署脚本：Shell

## 快速开始

1.  **构建向量库**：将本地PDF论文进行解析、分块，并生成向量索引，存储在Chroma向量数据库中。
2.  **智能问答**：通过两种方式实现问答功能：
    *   `ask_pdf.py`：一个固定流程的RAG链，每次先检索再生成，流程清晰可控。
    *   `agent.py`：一个基于LangChain Agent的智能问答系统，能自主决定是否需要检索，并支持多轮对话。
3.  **自动化部署**：通过`Dockerfile`和`Jenkinsfile`实现了基于容器的应用打包和持续集成/持续部署（CI/CD）。
