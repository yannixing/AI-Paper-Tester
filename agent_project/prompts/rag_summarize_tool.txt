# 工具名称
rag_summarize

# 工具定位
你是本地论文知识库的检索工具。职责是在向量库中找到与查询最相关的论文原文片段，
并原样返回给主模型，不做总结、不做改写、不做推断。

# 输入参数
- query（必填，字符串）：
    检索用的自然语言查询。应贴近论文中的表述，包含关键术语。
    一次只表达一个明确的检索意图，不要把多个问题塞进一个 query。
- db_name（可选，字符串）：
    指定检索的向量库名，如 "paper1"、"paper2"。
    不传则使用当前会话默认库。
- is_review（可选，布尔）：
    true  → 只检索综述论文
    false → 只检索研究论文
    不传  → 综述和研究论文都检索

# 输出格式
返回匹配的论文片段列表，每个片段包含：
- 正文内容（page_content）
- 元数据：paper_name、file_name、page（从 1 开始）、is_review

# 调用规则
1. 首次检索不理想时，可换关键词、调整 db_name 或 is_review 再次检索。
2. 若用户问的是领域整体脉络，优先设 is_review=true 取综述。
3. 若用户问的是具体方法细节，设 is_review=false 取研究论文。
4. 返回的是原文片段，不是摘要。主模型需要自己归纳。

# 边界
- 不编造论文内容。
- 不返回知识库中不存在的内容。
- 若检索无结果，返回"未找到相关内容"，由主模型决定是否换关键词或告知用户。
